
# Page 1: goals
The LLM suggests a few goals the user might want based on their situation. If they are a toddler a new game, if they are 50 early retirement, if they don't have a house buy one, if they are rich and like cars maybe buy a Ferrari, etc. The user can confirm them or add their own.
User adds goals with a free form text, LLM is allowed one round of questions. Suggestions appear in desaturated ovals at the start of the text box that have an option to edit, confirm or delete. 
A tiny disclaimer warns that we use AI and analyze the data the bank has, combined with public data and what the use inputs. 

# Page detais: facts and assumptions
Not on the main path, the other pages links it under "see the data we are working with"
The LLM reads the data, and tells the user what it knows, and what it's assuming, in a list. The user can edit the list directly, or chat at the bottom to review all items in view of the new data.
